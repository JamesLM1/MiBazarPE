MiBazarPE - Paquete de la mascota Bazi

Contenido:
- 01_conceptos: imágenes base del personaje elegido.
- 02_bocetos_funcionales: expresiones y poses para login, registro e interacción.
- 03_guias_para_animacion: hojas guía para producción y futura animación en Rive/Lottie.

Nomenclatura:
- 01 a 03 = concepto visual base
- 04 a 09 = poses y reacciones funcionales
- 10 a 14 = hojas guía para animación

Sugerencia de uso:
1. Elegir la pose base final.
2. Usar las hojas guía como referencia visual.
3. Redibujar/vectorizar por capas para Rive.
4. Separar cabeza, ojos, párpados, cejas, boca, brazos y torso para animación.
